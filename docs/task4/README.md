# Задача 4: Свёртка на GPU

В данной задаче реализовано ускорение свёртки изображений с использованием **OpenCL**.

## Результаты бенчмарков

Замер проводился в режиме пайплайна для **10 изображений в разрешении 4K** (3840x2160).
Цепочка фильтров: `gauss 5x5 -> sharpen 3x3`.

| Режим | Тип | Среднее время (мс) | Ускорение (vs seq) |
| :--- | :--- | :--- | :--- |
| **Sequential** | CPU (1 поток) | ~75 000 | 1.00x |
| **Parallel Rows** | CPU (Multi-thread) | ~13 000 | ~5.8x |
| **GPU (OpenCL)** | GPU | **~1 600** | **~45.0x** |
| **Hybrid** | CPU + GPU | ~7 000 | ~10.5x |
